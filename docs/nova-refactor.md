# 全站 Nova 视觉重构（2026-10-21）

目标：在 Flask/Jinja + 原生 HTML/CSS/JS 上实现 Nova 风格的教务工作台。保留全部 DOM 业务契约、API、存储、权限、支付流程与五套外观，不新增框架或构建步骤。

## 页面与组件清单

- 用户端：首页、日程表（编辑、手势、历年和其他班级）、成绩（概览、按学期、补考、不及格、绩点）、教学评估、实验提交、服务介绍、反馈、会员与邀请返佣、更多设置。
- 后台：登录、用户增长、在线监控、会员、公告、广告、反馈、提现、系统配置、微信绑定、个人状态。
- 独立页面：广告详情/无活动、维护页；维护景观保留独立渲染与控制。
- 浮层：登录、免责声明、换绑、课程详情/编辑、考试、导出、历年查询、确认、支付/订单、提现、反馈详情、公告、小程序、外观、后台编辑与详情、Toast、下拉。

## 审计与实施决策

已有 CSS cascade layers 和五套主题；旧样式仍承载大量课表布局，直接删除存在兼容风险。沿用 layers，在 workspace 层提供按组件组织的 Nova 样式，颜色/尺寸 Token 归入 taste-theme，后台布局归入 admin-workspace；可选材质层保持优先。

颜色以 zinc 中性灰为基底、延续品牌蓝 #2055a2。默认画布 #fafafa、表面 #fff、文字 #18181b、边框 #e4e4e7。深色延续项目既有纯黑画布与中性黑灰表面。中文系统字体，正文 14–16px、标题 24–30px、标签 12–14px，数字 tabular。4px 间距基准、8px 控件/12px 面板圆角、浮层轻阴影，44px 触控目标。用户端 3/2/5、后台 3/1/7（变化/动效/密度）。

执行顺序：共享 token/控件 → 导航和首页 → 课表与各功能页 → 后台与独立页 → 响应式/交互 → 浏览器验证。Lucide 官方 SVG 本地托管；不依赖 CDN 或运行时图标扫描。简单过渡用 CSS 并尊重 reduced-motion。

## 验证重点

- 真实 Jinja 渲染，离线拦截 API，320/390/768/1100/1440px，无页面级横向溢出。
- 每个用户页和后台栏目、明暗模式、五套外观、登录/确认/公告/编辑/支付浮层。
- 导航选中、键盘焦点、Escape/遮罩、表单标签、按钮对比度、长文本、加载/空/错误。
- 现有 Node 检查基线：306 通过，8 跳过；浏览器用例使用隔离测试依赖。
- 不进行真实支付、生产部署或写入真实教务数据。

## 验证结果

- Node 前端检查：314 项，306 通过、8 跳过、0 失败。
- 新全站浏览器检查：410 项断言；真实 Jinja 条件分支、全部用户页/后台栏目、320/390/768/1100/1440px、明暗与五套外观、CSSOM 分层、正常课程详情动画、焦点返回、广告开关及会员页开关。
- 既有离线浏览器：支付运营期限确认 4 组合；密钥/评教确认 4 组合；后台提现文字/转义/审批 10 组合，全通过。
- 隔离 Flask/临时 SQLite：课表编辑器 8 组合；固定节次、新旧年级作息、保存/拖动/撤销/提醒/导出 16 组合，全通过。旧用例假设登录自动恢复课表，临时测试副本中显式调用原导航进入课表后执行原断言；未改变生产启动行为。
- DOM 契约比对：三个模板原有 ID、事件处理器和字段 name 无缺失。修改的 JavaScript 语法及 Git 空白检查通过。
- 独立审查发现课程共享过渡结束后重复弹入，已将课程详情完全排除通用弹窗动画，正常动效复测通过。

验证全部使用离线固定数据或临时数据库，没有访问真实学校账号、执行真实支付或部署生产。真实 VPN/教务登录与第三方支付服务仍需发布前在授权环境联调。静态资源沿用服务器已有的修改时间版本机制，修改的动态图标模块同步更新入口版本。

依赖：生产仅新增官方 Lucide SVG 与 ISC 许可；Playwright 和 lucide-static 安装于 /tmp/urp-nova-tools 作为本地工具，没有新增前端运行时依赖或构建工具。
