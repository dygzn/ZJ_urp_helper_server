# URP 教务助手移动端 UX 优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变后端业务的前提下，统一 URP 教务助手的触控、导航、弹窗、异步反馈和窄屏布局，让普通用户端、管理员端与活动详情页在手机上可读且不易误触。

**Architecture:** 新增一个无框架 UMD 兼容的 `ui-ux.js`，只承载可复用的页面名、访问提示、弹窗可关闭性和焦点筛选逻辑；`main.js` 继续负责业务 API，但统一调用集中式 UI 状态函数。样式采用文件末尾的 UX 收口层覆盖历史追加规则，避免大规模重排已有页面；页面 DOM 保留受限页面原内容，通过锁定提示而不是覆盖内容实现访客流程。

**Tech Stack:** 原生 HTML/CSS/JavaScript、Node.js `node:test`、Flask 本地服务、Playwright CLI。

**Spec:** `docs/superpowers/specs/2026-09-03-mobile-ux-design.md`

## Global Constraints

- 不修改 Flask 路由、数据库 schema、支付接口、会员价格、教务抓取逻辑或广告统计口径。
- 不把现有 SPA 迁移到 React/Vue 等框架。
- 保留工作区中已有的广告转化相关未提交改动，不执行 reset、checkout 或覆盖式重写。
- 所有手机端可操作控件的可见热区不小于 44px；关键表单输入和主要按钮优先使用 48px 高度。
- 保留 Clipboard API 不可用时的 textarea 复制回退；localStorage、sessionStorage 或 History API 不可用时主要流程仍可继续。
- 修改已有脏文件时只增量编辑与本任务相关区域，不对整文件做格式化或换行风格重写。
- 测试命令使用 Node 内置测试运行器；仓库没有可运行的 pytest 测试套件。

  function setPageAccessLock(pageName, locked) {
      const page = document.getElementById(`page-${pageName}`);
      const gate = page?.querySelector('[data-page-access-gate]');
      if (!page || !gate) return;

      page.classList.toggle('is-access-locked', locked);
      gate.hidden = !locked;
      if (locked) {
          const copy = URPUI.getGuestAccessCopy(pageName);
          gate.innerHTML = `
              <div class="page-access-gate-icon" aria-hidden="true">锁</div>

              <button class="btn-primary" type="button" onclick="showLoginModal()">${escapeFeedbackHtml(copy.button)}</button>`;

      }
  }
