# 课程表周末列动态显示设计

## 背景

课程表前端已经根据当前显示周次的课程判断周六或周日是否有课，并给课程内容网格切换 `no-weekend` 状态。但是模板中的周六、周日表头缺少 `schedule-header-weekend` 标记，导致无周末课程时内容列会隐藏，表头仍然显示或发生列错位。显示空周次时只清空课程内容，也可能保留上一周的周末显示状态。

## 目标

- 当前显示周次的周六、周日都没有课时，只显示周一至周五。
- 当前显示周次的周六或周日任一天有课时，显示周一至周日，并展示实际周末课程。
- 切换周次、查看其他班级课表和显示空周次时，每次都依据当前数据重新计算。
- 不修改后端课表接口、缓存文件格式和课程解析逻辑。

## 方案

采用现有前端 `hasWeekend` 判断和 CSS 状态切换机制，完成缺失的 DOM 标记和空状态同步：

1. 在 `templates/index.html` 的周六、周日表头添加 `schedule-header-weekend` 类，使现有 `.schedule-header.no-weekend .schedule-header-weekend` 规则真正生效。
2. 保留 `displaySchedule()` 当前的判断规则：`daysCourses[6]` 或 `daysCourses[7]` 任一非空即显示完整七天。
3. 空周次也通过统一的课程表渲染状态更新路径处理，确保清空课程后表头恢复为五天模式，不继承上一周状态。
4. 周末任一天有课时同时显示周六、周日两列，保持星期列连续且课程位置不偏移。

不采用动态重建整个表头的方案，因为现有模板和 CSS 已具备五列/七列布局，只缺少正确标记；重建表头会扩大改动范围。也不在后端返回额外的周末标志，因为显示规则完全可以由当前周课程数据确定。

## 数据流

1. `loadSchedule()` 或其他班级课表入口取得当前周课程数组。
2. `displaySchedule()` 按 `星期` 将课程分入 1 至 7。
3. 前端计算周六、周日是否至少有一门课。
4. 有周末课程时移除 `no-weekend`，展示七列；没有时添加 `no-weekend`，隐藏两个周末表头和内容列。
5. 空周次按“没有周末课程”处理，展示五列表头并显示原有空周提示。

## 异常与兼容

- `星期` 不是 1 至 7 的无效课程记录不参与周末判断，沿用当前课程过滤行为。
- 桌面端和移动端继续使用现有五列/七列 CSS 网格规则。
- 不改变课程卡片详情、周次选择、课程表刷新或其他班级课表的数据结构与交互。

## 测试

增加前端回归测试，覆盖：

- 仅工作日有课时，周六、周日表头和内容列均隐藏。
- 周六有课或周日有课时，周六、周日两列均显示，课程位于正确星期。
- 从有周末课程的周切换到无课周时，周末列不会残留。

最后运行现有 VPN 回归测试与应用导入/语法检查，确认本次前端改动不影响现有业务。
