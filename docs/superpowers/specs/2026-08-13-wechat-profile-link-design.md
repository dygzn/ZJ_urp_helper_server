# 微信个人资料协议链接设计

## 目标

将“找我做事”页面中的微信联系入口从当前协议地址改为用户指定的个人资料协议地址，使用户点击后尝试直接唤起微信并进入微信号 `Dygzn123` 的个人资料或添加好友页面。

## 改动范围

- 微信链接的 `href` 改为 `weixin://contacts/profile/Dygzn123`。
- 保留现有 `<a>` 超链接结构，不增加内联 JavaScript 跳转函数。
- 保留 `data-copy-text="Dygzn123"`，因此点击时仍会尝试复制微信号并显示现有复制反馈。
- 保留微信入口的现有文字、样式、可访问性属性和新窗口属性。
- QQ 链接及其复制行为不做任何修改。

## 交互流程

1. 用户点击微信入口。
2. 现有委托点击处理器尝试把 `Dygzn123` 写入剪贴板。
3. 浏览器继续执行超链接的默认行为，尝试打开 `weixin://contacts/profile/Dygzn123`。
4. 是否成功唤起微信由用户设备、微信安装状态和浏览器对自定义协议的限制决定；网页不拦截失败，也不增加自动回退。

## 测试

- 先修改模板测试，使其期望微信链接为 `weixin://contacts/profile/Dygzn123`，并确认测试因旧链接而失败。
- 再修改模板中的微信 `href`，使目标测试通过。
- 运行现有 Python 和 Node 测试，确认联系方式复制、QQ链接及其他功能没有回归。
- 运行 JavaScript 语法检查与 `git diff --check`。

## 非目标

- 不验证或承诺该非 HTTP 协议在所有浏览器、桌面端或移动端均可工作。
- 不增加二维码、HTTP 回退地址、设备识别或浏览器提示。
- 不修改后台状态管理和“找我做事”页面的其他内容。
