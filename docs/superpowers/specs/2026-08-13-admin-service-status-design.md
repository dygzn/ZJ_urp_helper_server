# “找我做事”管理员接单状态设计

## 目标

在用户侧导航增加“找我做事”页面，让用户查看管理员当前状态、是否接单和最后更新时间；在管理后台提供对应的状态编辑入口。

## 本次范围

- 用户侧导航名称固定为“找我做事”。
- 用户页仅展示状态文字、接单状态和最后更新时间。
- 后台支持快捷状态和自定义状态文字。
- “可接单 / 暂不接单”作为独立开关，不从状态文字自动推断。
- 本次不展示广告词、联系方式或历史完成任务。

## 数据模型

新增 `admin_service_status` 单行表，以固定主键 `id = 1` 保存全局状态：

- `status_text`：管理员状态文字。
- `accepting_orders`：是否接单，`1` 表示可接单，`0` 表示暂不接单。
- `updated_at`：最后更新时间，使用 ISO 格式字符串。

SQLite 与 MySQL 都创建同名、同语义的表。未保存记录时不强制插入默认行，读取接口直接返回“暂未设置状态”、暂不接单和空更新时间。

## 接口

### 公开读取

`GET /api/service-status`

成功返回：

```json
{
  "success": true,
  "data": {
    "status_text": "空闲",
    "accepting_orders": true,
    "updated_at": "2026-08-13T12:00:00"
  }
}
```

该接口不要求设备绑定，访客也能查看。

### 后台读取与更新

- `GET /api/admin/service-status`
- `PUT /api/admin/service-status`

两个接口都使用现有 `@require_admin` 保护。更新请求包含 `status_text` 和布尔值 `accepting_orders`；状态文字去除首尾空白后不能为空，并限制为 40 个字符。保存采用更新或插入单行记录的方式。

## 用户端交互

侧边栏新增“找我做事”导航项，并新增对应 SPA 页面。用户进入该页时才请求公开状态接口。页面显示：

- 当前状态文字。
- “当前可接单”绿色标识，或“暂不接单”灰色标识。
- 最后更新时间；从未保存时显示“尚未更新”。

加载中显示加载提示；接口失败时显示错误提示和“重新加载”按钮，不影响其他页面。

## 管理后台交互

后台导航新增“个人状态”标签页。表单包含：

- 快捷状态按钮：空闲、上课、睡觉、忙碌。
- 自定义状态文本框，点击快捷状态会填入文本框，管理员仍可继续修改。
- “可接单 / 暂不接单”开关。
- 保存按钮与结果提示。

进入标签页时读取当前状态。保存成功后更新页面中的最后更新时间，失败时保留用户输入并显示错误。

## 样式与兼容性

沿用现有用户端卡片、后台表单、按钮和响应式布局风格，不引入新依赖。用户端和后台在窄屏下保持单列布局。所有动态文本使用 `textContent` 或 HTML 转义后渲染，避免状态文字造成脚本注入。
