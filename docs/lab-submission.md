# 实验提交部署与核验

实验提交固定连接 `http://192.168.16.235`，不接受用户提供目标 URL。部署服务器必须能通过 VPN 访问该内网地址；仅前端浏览器连 VPN 不够。实验站是 HTTP，密码在服务器到实验站的 VPN 链路上以 HTTP 表单传输，需确保 VPN 链路可信。

安装更新后的 `requirements.txt`，并设置稳定的 `LAB_CREDENTIAL_KEY` 环境变量。可在安全的部署环境中运行 `.venv/bin/python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` 生成密钥。密钥应由部署环境的密钥管理保存，不写入仓库；更换密钥会使已绑定的实验站密码无法解密，用户须重新绑定。未配置密钥时，用户仍可输入临时密码查询，但不能绑定密码。

实验站会话在当前 Python 进程内保存 30 分钟，不跨进程共享。若部署多个 worker，应启用会话粘性或改用共享会话存储；进程重启后用户需刷新验证码重新查询。

实验任务列表保留原站默认的“按课程”模式：按所选学期展示课程实验任务，并沿用每条记录的预习报告、实验报告入口。原站“按实验项目”模式可能没有记录，因此不要在查询后自动切换到该模式。

上传入口允许用户选择 PDF、DOC/DOCX、JPG/JPEG、PNG；只有 PDF 会提交到本站接口。选择 Word 或图片时，前端展示 iLovePDF 对应转换页的外链，用户自行决定是否将文件上传给第三方，下载 PDF 后返回本站重新选择。后端仍只接受 PDF。

上线核验：用可用的初级会员账号检查后端自动识别验证码并登录、默认最新学期、切换学期、每项的两个报告入口。用专门准备的测试 PDF 分别提交两种报告，再回到实验站核对是否实际收件。当前抓包中的上传请求没有返回响应，因此接口只会提示“已发送，请核对”，不会宣称提交成功。
