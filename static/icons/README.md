# Lucide SVG

来源：https://lucide.dev / https://github.com/lucide-icons/lucide
版本：lucide-static 1.61.0，ISC 许可，详见 LUCIDE-LICENSE。

模板中的静态图标使用官方 SVG 路径；动态空/成功状态复用 lucide.svg 中的三个 symbol。统一 24×24 viewBox、1.75px 描边、currentColor，无外部 CDN 或运行时依赖。图标仅为装饰，按钮名称由可见文字/aria-label 提供。更新时从官方 lucide-static 包同步 SVG 与许可，不手绘路径。
